# AttendAI

This repository now includes a small Pac-Man inspired game prototype alongside the
original AttendAI demo script.

## Pac-Man mini game

Run the arcade demo locally with:

```bash
pip install pygame
python pacman.py
```

Use the arrow keys to move, collect every pellet to win, and avoid the roaming
ghosts. Press `SPACE` to restart after a win or loss, and `ESC` to exit.
